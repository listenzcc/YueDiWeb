
# 睡眠障碍队列研究 - 文件上传管理系统

## 项目简介

这是一个专为浙江省"尖兵领雁+X"科技计划项目开发的睡眠障碍队列研究数据收集系统。该系统提供安全、高效的文件上传和管理功能，支持医疗影像数据和表单数据的收集与管理。

## 快速开始使用

### 访问系统

打开浏览器访问系统地址（由管理员提供），即可开始使用。

## 用户使用指南

### 1. 账户注册

1. **打开注册页面**
   - 在系统首页点击 **"注册新账户"** 按钮

2. **填写注册信息**
   - **用户名**: 输入您的用户名（3-30个字符）
   - **邮箱**: 输入有效的邮箱地址
   - **密码**: 设置至少6位密码
   - **确认密码**: 再次输入相同密码

3. **完成注册**
   - 点击 **"注册"** 按钮
   - 注册成功后会自动登录并跳转到主界面

### 2. 用户登录

1. **进入登录页面**
   - 系统首页默认显示登录表单

2. **输入登录信息**
   - **邮箱**: 输入注册时使用的邮箱
   - **密码**: 输入您的密码

3. **登录系统**
   - 点击 **"登录"** 按钮
   - 登录成功后会显示导航菜单

## 📤 上传二进制文件（影像数据）

### 支持的文件类型

- **图像文件**: JPG, PNG, GIF, BMP, WebP
- **视频文件**: MP4, AVI, MOV, WMV, FLV
- **文档文件**: PDF
- **其他**: ZIP, RAR等压缩文件
- **最大文件大小**: 单个文件最大100GB

### 详细上传步骤

1. **选择上传类型**
   - 登录后点击导航栏的 **"上传影像文件"** 按钮

2. **填写基本信息**
   - **单位名称**: 输入您的单位/医院名称
   - **科室名称**: 输入具体科室（如神经内科、睡眠中心等）
   - **患者姓名**: 输入患者姓名
   - **数据类型**: 选择数据类型
     - MRI: 磁共振成像
     - EEG: 脑电图
     - CT: 计算机断层扫描
     - Other: 其他类型

3. **上传文件**
   - **方法一：拖拽上传**
     - 直接将文件拖拽到上传区域
     - 支持同时拖拽多个文件
   - **方法二：点击选择**
     - 点击 **"选择文件"** 按钮
     - 在文件选择器中选择一个或多个文件

4. **监控上传进度**
   - 上传过程中会显示进度条
   - 显示当前上传的文件名和进度百分比
   - 上传完成后会显示成功提示

5. **查看上传结果**
   - 成功上传的文件会显示在文件列表中
   - 可以查看文件大小、上传时间等信息

### 注意事项

- 确保网络连接稳定，大文件上传可能需要较长时间
- 如果上传失败，请检查文件大小是否超过限制
- 上传的文件会自动按用户分类存储

## 📊 上传和管理表单数据

### 支持的文件格式

- **Excel文件**: .xlsx, .xls
- **CSV文件**: .csv
- **多个文件**: 系统会自动合并多个文件的数据

### 详细操作步骤

1. **进入表单上传页面**
   - 点击导航栏的 **"上传表单文件"** 按钮

2. **上传表单文件**
   - **拖拽上传**: 将Excel/CSV文件拖拽到上传区域
   - **点击选择**: 点击 **"📂 选择文件"** 按钮选择文件
   - 支持同时上传多个文件，系统会自动合并

3. **数据预览和编辑**
   - 文件上传后，数据会自动显示在交互式表格中
   - 表格支持分页显示，默认每页10行
   - 可以调整每页显示行数（5/10/15/25/50/100行）

4. **编辑表格数据**
   - **添加新行**: 点击 **"➕ 添加新行"** 按钮
   - **删除行**: 选中要删除的行，点击 **"🗑️ 删除选中行"**
   - **直接编辑**: 点击表格中的任意单元格进行编辑
   - **清除筛选**: 点击 **"🔍 清除筛选"** 清除所有筛选条件

5. **数据筛选和搜索**
   - 点击表格列标题可以进行筛选
   - 支持文本搜索和条件筛选
   - 可以同时应用多个筛选条件

6. **保存和导出数据**
   - **上传到服务器**: 点击 **"📤 上传表单"** 按钮保存数据
   - **导出Excel**: 点击 **"💾 导出Excel"** 下载当前数据
   - **清空表格**: 点击 **"🗂️ 清空表格"** 清除所有数据

7. **表单命名**
   - 在上传前，可以在 **"表单名称"** 输入框中为数据命名
   - 这有助于区分不同的数据集

### 表格操作技巧

- **选择多行**: 按住Ctrl键点击选择多个不连续行
- **快速导航**: 使用分页控件浏览大量数据
- **数据验证**: 系统会自动验证数据格式
- **实时保存**: 编辑后的数据会实时保存到浏览器本地

## 📁 文件管理

### 查看已上传文件

1. **进入文件管理**
   - 点击导航栏的 **"文件管理"** 按钮

2. **浏览文件列表**
   - 显示所有已上传的文件
   - 按上传时间倒序排列（最新文件在前）
   - 显示文件大小、类型、上传时间

3. **搜索文件**
   - 在搜索框中输入文件名关键词
   - 点击 **"搜索"** 按钮筛选文件
   - 支持部分匹配搜索

4. **文件操作**
   - **下载文件**: 点击文件名或下载链接
   - **查看详情**: 查看文件详细信息
   - **刷新列表**: 点击 **"刷新"** 按钮更新文件列表

### 存储空间管理

- 系统会显示您的存储使用情况
- 配额信息：当前使用量 / 总配额
- 可视化进度条显示存储使用百分比

## 👤 个人中心

### 查看账户信息

- 显示用户名和邮箱地址
- 查看存储空间使用情况
- 显示账户状态信息

### 修改密码

1. **进入个人中心**
   - 点击导航栏的 **"个人中心"** 按钮

2. **填写密码信息**
   - **当前密码**: 输入现在的密码
   - **新密码**: 输入新密码（至少6位）
   - **确认新密码**: 再次输入新密码确认

3. **保存更改**
   - 点击 **"修改密码"** 按钮
   - 密码修改成功后会显示确认消息

## 🔐 安全和注意事项

### 数据安全

- 所有上传文件使用阿里云OSS安全存储
- 用户数据隔离，每个用户只能访问自己的文件
- 密码使用加密存储
- 传输过程使用HTTPS加密

### 使用建议

- 定期备份重要数据
- 使用强密码并定期更换
- 及时清理不需要的文件以节省存储空间
- 大文件上传时请确保网络稳定

如遇到使用问题，请联系系统管理员或技术支持团队。
